# Spec: stocks-52w-high

## 목표

주가 브리핑의 모든 시세 줄에 **52주 고점 대비 하락률**과 **52주 범위 내 현재 위치**를 덧붙여,
"어제보다 올랐나"뿐 아니라 "역사적으로 지금 어디쯤인가"를 알 수 있게 한다.

## 요구 동작

- 시세를 조회하면 각 `Quote`가 52주 고점 대비 하락률(`drawdown_pct`)과 52주 범위 내
  위치(`range_pct`)를 함께 갖는다.
- 두 값은 Yahoo v8 chart 응답의 `meta.fiftyTwoWeekHigh` / `meta.fiftyTwoWeekLow`에서 얻는다.
  **추가 HTTP 호출을 하지 않고, `range` 파라미터도 바꾸지 않는다.**
- 계산식:
  - `drawdown_pct = (price - high) / high * 100` — 보통 0 이하다
  - `range_pct = (price - low) / (high - low) * 100` — **0~100으로 클램프한다**
- 지수·환율·관심 종목 **모든 시세 줄**에 표시한다.
- 표시 형식은 시세 줄 다음의 들여쓴 한 줄이다.

  ```
  삼성전자 (005930.KS)  271,000  ▲ +11.07%
     52주 고점 대비 -27.6%  (범위 내 66%)
  ```

  - 하락률은 소수 1자리, 범위 위치는 정수다.
  - `drawdown_pct >= 0`이면 `   52주 신고가` 만 쓰고 범위 위치를 덧붙이지 않는다
    (신고가면 범위 위치가 100%로 자명하므로 중복이다).
  - `drawdown_pct`가 `None`이면 **줄 자체를 생략한다.**

## 불변 조건

- **CRITICAL: 등락률(`change_pct`) 계산 방식을 바꾸지 않는다.** 여전히 `close` 배열에서
  `None`을 제거한 유효값의 마지막 두 개로 계산하며, `meta.chartPreviousClose`를 쓰지 않는다.
- 52주 값을 얻지 못해도 **시세 조회는 성공이다.** `Quote`를 버리지 않는다 — 종가와 등락률은
  이미 유효하기 때문이다.
- 52주 값 때문에 추가 HTTP 요청을 하지 않는다.
- `range_pct`는 항상 0 이상 100 이하이거나 `None`이다.
- 기존 테스트를 깨뜨리지 않는다. `Quote`의 새 필드는 **기본값 `None`으로 뒤에 추가**해
  기존 생성 코드가 그대로 동작해야 한다.
- 발송 메시지에 시크릿·환경 변수 값이 들어가지 않는다.

## 범위 제외

- 52주 고점·저점의 **원본 값**을 화면에 표시하는 것 (하락률과 위치만 쓴다)
- 급등락 블록(`_render_mover`)에 이 지표를 추가하는 것 — 관심 종목 블록에 이미 나온
  종목의 상세이므로 중복이다
- 사상 최고가(all-time high) 기준 — Yahoo가 주지 않아 `range=max` 조회가 필요하다
- 최근 1개월 등 다른 기간의 고점
- 고점 대비 하락률에 따른 알림·경고·매매 신호
- LLM 해설에 이 지표를 넣는 것

## 엣지 케이스

| 상황 | 처리 |
| --- | --- |
| `meta`에 `fiftyTwoWeekHigh`/`Low` 키가 없음 | 두 값 모두 `None`. 시세 조회는 성공으로 본다 |
| 두 값 중 하나가 `null` | 두 값 모두 `None` |
| 두 값이 숫자로 변환되지 않음 | 두 값 모두 `None`. 예외를 올리지 않는다 |
| `high <= 0` | 두 값 모두 `None`. 0으로 나누지 않는다 |
| `high == low` (범위 폭 0) | `drawdown_pct`는 계산하고 `range_pct`만 `None` |
| 종가가 52주 고점보다 높음 | `drawdown_pct`가 양수가 된다. 그대로 담고 렌더가 `52주 신고가`로 표시한다. 우리는 종가를 쓰는데 `fiftyTwoWeekHigh`는 장중 고가를 포함하므로 실제로 발생할 수 있다 |
| 종가가 52주 저점보다 낮음 | `range_pct`가 음수로 계산되므로 `0`으로 클램프한다 |
| `low > high` (데이터 이상) | 클램프가 흡수한다. 별도 분기를 두지 않는다 |
| `drawdown_pct`가 `None` | 그 줄 전체를 생략한다. 빈 괄호나 `-` 를 남기지 않는다 |
| 지표가 붙어 메시지가 4096자를 넘음 | 기존 `tghtml.pack`이 블록 경계에서 나눈다. 새 분할 로직을 만들지 않는다 |

## 외부 인터페이스

CLI·환경 변수·워크플로에 변경이 없다. 발송 메시지의 시각적 형식만 바뀐다.

`Quote` 데이터 구조가 확장된다(기존 소비자는 영향 없음):

```python
@dataclass(frozen=True)
class Quote:
    ticker: Ticker
    price: float
    change_pct: float
    currency: str
    as_of: date
    drawdown_pct: float | None = None   # 52주 고점 대비 %. 보통 0 이하
    range_pct: float | None = None      # 52주 범위 내 위치 %. 0~100
```

## 확정 근거

- **52주 기준** — Yahoo v8 chart 응답의 `meta`가 `fiftyTwoWeekHigh`/`fiftyTwoWeekLow`를 이미
  담고 있음을 계획 단계에서 실측했다(삼성전자 374500/67500, 애플 344.57/223.78). 추가 호출도
  `range` 변경도 없이 얻을 수 있어 가장 싸고, 주식에서 가장 널리 쓰이는 기준이기도 하다.
  사상 최고가는 `range=max` 조회가 필요해 응답이 커지고 429 위험이 올라간다.
- **하락률 + 범위 내 위치** (저점 대비 상승률이 아니라) — 사용자가 "몇 % 오른 상태인지"도
  원했으나, 고점 대비는 정의상 항상 0 이하라 상승을 표현하지 못한다. 저점 대비 상승률은
  오래 오른 종목에서 `+301.5%`(삼성전자 실측)처럼 커져 감이 오지 않는다. 범위 내 위치는
  0~100으로 갇혀 있어 "지금 높은 편인가 낮은 편인가"가 한눈에 들어온다.
- **모든 시세 줄에 적용** — 사용자가 지수·환율 포함을 선택했다. 지수 블록이 3줄에서 6줄로
  늘어나지만 분할은 `pack`이 처리한다.
- **신고가일 때 범위 위치를 생략** — 신고가면 범위 내 위치가 100%로 자명해 중복이다.
- **원본 고점·저점 값을 저장하지 않음** — 화면에 나오지 않는 값이다. 요청되지 않은 필드를
  미리 만들지 않는다.
- **`range_pct`만 클램프하고 `drawdown_pct`는 클램프하지 않음** — `drawdown_pct`의 양수는
  버그가 아니라 "신고가"라는 의미 있는 신호이고, 렌더가 그것으로 분기한다.
